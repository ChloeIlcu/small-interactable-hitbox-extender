\# Small Interactable Hitbox Extender



A small client-side QoL Fabric mod that lets you configure the interaction hitboxes of buttons and levers.



\## Features



\- Configure button and lever hitboxes independently

\- Three hitbox modes:

&#x20; - Vanilla — uses Minecraft's default hitbox

&#x20; - Flat — expands the hitbox across the full face the button or lever is attached to

&#x20; - Full Block — expands the hitbox to the entire block space

\- In-game configuration screen

\- Optional Mod Menu integration

\- Standalone keybind for opening the config screen

\- Settings persist between launches

\- Client-side only



\## Configuration



You can open the configuration screen in two ways:



\- Assign a key to \*\*Open SIHE Config\*\* under Options → Controls → Key Binds

\- If Mod Menu is installed, use its \*\*Configure\*\* button



Mod Menu is optional.



\## Requirements



\- Minecraft 26.1.2

\- Fabric Loader

\- Fabric API



\## Installation



1\. Install Fabric Loader for Minecraft 26.1.2.

2\. Install Fabric API.

3\. Place the SIHE `.jar` in your `mods` folder.

4\. Launch the game and configure the hitboxes however you like.
