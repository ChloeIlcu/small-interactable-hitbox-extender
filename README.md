# Small Interactable Hitbox Extender

A small client-side Fabric QoL mod by **Chloe_ilcu** that lets you configure the interaction/selection hitboxes of Minecraft buttons and levers.

## Hitbox modes
- **Vanilla** — keeps Minecraft's original hitbox.
- **Flat** — expands the hitbox across the full attached block face while keeping it shallow.
- **Full Block** — expands the hitbox to the entire 1×1×1 block space.

Buttons and levers can be configured independently.

## Defaults
Both buttons and levers default to **Vanilla**, so installing the mod does not change interaction hitboxes until configured.

## Configuration
The config screen is available through **Mod Menu** when Mod Menu is installed. Settings persist in `config/small-interactable-hitbox-extender.properties`.

A standalone Controls keybind for opening this same screen is planned for the release build so Mod Menu can remain fully optional.

## Compatibility
- Minecraft 26.1.2
- Fabric Loader 0.19.3+
- Java 25
- Client-side only
- Mod Menu is optional
